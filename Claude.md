# Schul-PIP (code name Lernwerk): iOS app, SwiftUI + SwiftData, iOS 17+

- Code comments, commit messages, docs: English. UI strings: German, "du" form.
- The Xcode project is generated by XcodeGen (project.yml). Everything under Lernwerk/ and LernwerkTests/ is picked up automatically. Never edit an .xcodeproj. Do not touch android/ or supabase/.
- Design system "Quill" (Lernwerk/Theme/): use Quill.* colors, .work()/.jersey() fonts, PageHeader, PixelCaption, QuillPrimaryButtonStyle, QuillOutlineButtonStyle, QuillProgressBar, StatusDot, QuillDivider. No hard-coded colors, no emojis. Light and dark mode and iPad + iPhone (horizontalSizeClass .compact) must work.
- Logic lives in plain Foundation structs/enums without SwiftUI, clock or global randomness (inject Date, Calendar and a seeded RNG, see SplitMix in PipRun.swift). Tests go to LernwerkTests/ in the style of SpacedRepetitionTests.swift. Views stay thin.
- Do not change the SwiftData schema (no new @Model, no new stored properties on existing models) and do not change SM-2 in SpacedRepetition.swift or AnswerCheck.swift.
- LLM calls go through LLMClient and StructuredOutput.complete and need a demo-mode answer like StudyAids.demo. The feature must work fully offline without any LLM.
- Swift cannot be compiled on Linux. If no Xcode is available: write simple, careful code, push to a feature branch and read the result of the GitHub Actions workflow "iOS" (xcodegen, unit tests, release build). Fix every failure until it is green. Never report "done" while it is red.
- Feature name: "Lernpfad". Mascot: Pip. Never use the name or assets of Duolingo.
